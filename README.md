# Apex Drive — Supercar Telemetry & Rental Platform

Интерактивная платформа аренды трековых и премиальных суперкаров с живой гоночной телеметрией, саундбордом выхлопных систем и Telegram-ботом с KYC-верификацией водительских прав.

## 🌟 Ключевой функционал

1. **Гоночный Кокпит UI:**
   - Эстетика спортивного кокпита (карбон, шкалы тахометра в красной зоне `#FF1801`, телеметрический неоновый зеленый `#00E676`, глубокий черный `#0C0D10`).
   - Динамический круглый тахометр с анимированной стрелкой оборотов двигателя (до 9000 RPM).
   - Шкалы мощности (л.с.) и крутящего момента (Нм).
   - Анимированный график разгона 0–100 км/ч с наложением кривой ускорения.
2. **Интерактивный Саундборд Звука Выхлопа (Exhaust Rev Soundboard):**
   - Кнопка «REV ENGINE / Запустить выхлоп» запускает процедурный синтез Web Audio API: нарастающий рев спортивного мотора (V8 biturbo / V10 atmospheric), переход на повышенную передачу и характерные выстрелы в выхлопной трубе (pops & bangs).
3. **Калькулятор аренды и депозита:**
   - Выбор дат аренды с автоматическим расчетом дней.
   - Проверка возраста водителя (от 21 года; для 21–24 лет применяется надбавка 20% за риск).
   - Пакеты суточного пробега: 200 км (базовый), 400 км (+10,000 ₽/день), Безлимит / Трек (+25,000 ₽/день).
   - Тарифы страхования: Базовый (полный залог) или VIP Shield (залог уменьшен на 50%).
   - Защита от бронирований в прошлом и блокировка броней свыше 30 дней подряд.
4. **Суперкар-парк:**
   - Porsche 911 GT3 RS (525 л.с., 0-100 за 3.2 с, 296 км/ч)
   - Ferrari F8 Tributo (720 л.с., 0-100 за 2.9 с, 340 км/ч)
   - Lamborghini Huracán EVO (640 л.с., 0-100 за 2.9 с, 325 км/ч)
   - McLaren 720S Spider (720 л.с., 0-100 за 2.9 с, 341 км/ч)
   - Audi R8 V10 Performance (620 л.с., 0-100 за 3.1 с, 331 км/ч)
5. **Telegram-бот (Aiogram 3.x):**
   - Каталог суперкаров с подробными характеристиками и стоимостью за сутки.
   - Проверка доступности машины на выбранные даты.
   - KYC-модуль: прием фотографии водительского удостоверения с проверкой формата и валидацией данных.
   - Моментальная отправка лида в Telegram владельцу клуба (@Idrisov_prod).

## 🚀 Запуск проекта

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск веб-приложения и API
```bash
python -m uvicorn backend.app:app --host 0.0.0.0 --port 3014 --reload
```
Веб-интерфейс доступен по адресу: `http://localhost:3014`

### 3. Запуск Telegram-бота
```bash
python -m bot.bot
```

### 4. Запуск тестов
```bash
pytest tests/ -v
```
