## [0.1.0-MVP] — 2026-11-11
### Добавлено
- Телеметрический интерфейс гоночного кокпита с текстурами карбона, тахометром и динамическими графиками разгона 0–100 км/ч.
- Интерактивный саундборд звука выхлопа (Exhaust Rev Engine) на Web Audio API со звуками ускорения и отстрелов (pops & bangs).
- Калькулятор аренды: расчет дней, страхового депозита, пакетов пробега и надбавки за возраст молодого водителя.
- Telegram-бот на Aiogram 3.x с витриной суперкаров, проверкой доступности дат и приемом фото водительских прав для KYC-верификации.
- SQLite хранилище для броней, суперкаров и верификации водителей.
- Модульные тесты для расчетов калькулятора, API и регистрации хэндлеров бота.
